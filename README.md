# sort_study

# ロボットへの指示書をつくれ！〜ソートアルゴリズム〜

ブラウザで動く、ソートアルゴリズムの体験教材です。
フローチャートの空欄をチームで選び、ロボットに実行させて、荷物を軽い順（昇順）に並べ替えます。

## ファイル

| ファイル | 内容 |
|---|---|
| `robot_app.html` | メインのアプリ。フローチャートの空欄を選び、ロボットに実行させる |
| `sort_animation.html` | 解説用。3つのソートの動きを1手ずつ再生する |
| `tenbin_tool.html` | 練習用。天秤で荷物を比べながら、手で並べ替える |

## 扱うソート

- 選択ソート
- バブルソート
- 挿入ソート

## 使い方

1. HTMLファイルをブラウザで開く（ダブルクリック、または公開ページのURLを開く）
2. 最初にパスワードを入力する
3. 問題文のポップアップを読んで閉じる（あとから「📋 問題文」ボタンで開き直せる）
4. 上のボタンで、ソートを選ぶ
5. フローチャートの黄色い空欄をクリックして、選択肢から選ぶ
6. すべての空欄を選んだら「▶ 実行」を押す
7. ロボットが指示書のとおりに動く。成功するとクリア
8. 間違っていたら、赤くなった空欄を選び直して、もう一度実行する

実行中は、一時停止、1手進む、早送り、結果まで飛ばす、が使えます。

## 動作環境

- パソコン（画面の大きさは、1280×600以上を想定）
- Google Chrome、Microsoft Edge を推奨
- インターネット接続は不要

## 技術メモ

- それぞれ、HTML・CSS・JavaScriptが1ファイルにまとまっています。ビルドは不要です
- 外部のライブラリやフォントは使っていません
- 外部への通信や、ブラウザへのデータ保存は行いません
